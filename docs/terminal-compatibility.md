# Terminal compatibility

How real terminals answer the probes a BBS host uses to identify a terminal and measure its screen, and what a host should do about it. Every row comes from a [probe board](../tools/probe_board/README.md) report recorded from that terminal. The reports are the fixtures in `test/fixtures/probe_board/`.

The tables between the markers below are generated from those fixtures:

```
node tools/probe_board/matrix.js --write
```

A test fails if they no longer match. To add a terminal, connect it to the board, copy its report into the fixtures (drop `summary`, set `peer` to `127.0.0.1`), and add it to `TERMINALS` in `tools/probe_board/matrix.js`.

**How each terminal was connected:**
- **Modern terminals** went straight to the board over telnet on loopback (Windows 11, default window size).
- **DOS programs** dialled it through DOSBox Staging's Hayes softmodem. The softmodem does the telnet negotiation, so TTYPE and NAWS are "none" for them. A DOS user dialling a BBS over a real telnet modem emulator looks the same.

## Tiers

| Tier | Meaning | Terminals |
|---|---|---|
| **1: cannot break** | A regression blocks a release. | SyncTERM, IcyTerm, NetRunner, TERMinator, RGTerm, Qodem; Telix 3.51, Procomm Plus, Terminate 5.00 |
| **2: supported** | Bugs get fixed, but don't block a release. | UTF-8 OS terminals (PuTTY, Windows Terminal, telnet.exe, xterm-family, iTerm2…); Telemate 4.21, Qmodem 4.6, Procomm 2.4.3; fTelnet, BadTerm, ZOC |
| **3: best effort** | Must not hang or corrupt anything; rendering may degrade. | Everything else |

**Not yet recorded:** RGTerm, Qodem, PuTTY, and Windows Terminal or other VT terminals over ssh. Rendering (what each terminal draws) is not covered yet; this page is about detection.

## What a host should do

### Size

Use, in this order:
1. **NAWS**, only if it is well formed and plausible, and agrees with a measurement when you have one.
   - **NetRunner** sends six bytes (`00 00 50 00 19 00`) and sends them without `WILL NAWS`.
   - **Windows telnet.exe** keeps only the low byte of each dimension: a 270-column window arrives as 14 columns.
2. **`CSI 255 n`**, but only from a terminal known to support it (SyncTERM, TERMinator, IcyTerm). **NetRunner and Qmodem answer it with the current cursor position**, so a host that takes any cursor report after it as the size gets the wrong size.
3. **`CSI 999;999 H` then `CSI 6 n`**, read one dimension at a time:
   - **231** means 999 wrapped at 256 (Procomm Plus wraps the width; Procomm 2.4.3 wraps both). Use 80 for that dimension.
   - **79 columns** is Telemate clamping the cursor at column 79 while drawing 80. Use 80.
   - **No movement** (the reply is where the cursor already was) is Qmodem ignoring an out-of-range move. Use the default.
   - **Telix** reports one row lower than the real position (its status line), and **Terminate** reports column;row. Find both by first moving the cursor to a known position whose row and column differ (a sentinel, e.g. row 2, column 7) and checking the reply.
4. **80x25** otherwise. Telix really has 23 rows and the Procomms 24.

### Identity

- **Trust DA, not TTYPE.** IcyTerm says `ANSI`; TERMinator says `syncterm` and answers DA exactly like SyncTERM (CTerm 1.332 versus 1.333; its `CSI < c` list lacks 5 and 7). NetRunner and Qmodem don't answer DA at all.
- NetRunner's TTYPE ends in a NUL byte: strip it.
- `CSI 5 n` is not a safe "are you there": NetRunner and Qmodem send a cursor report and telnet.exe sends `CSI c`.

### Probes that print

- **The CTerm probes** (`CSI < c`, `CSI = Ps n`, font select) leave a character or two on most DOS screens and on NetRunner. Clear the screen after detection.
- **Send XTVERSION, OSC queries and APCs only to a terminal already identified by DA.** XTVERSION prints on NetRunner, telnet.exe and five of the six DOS programs (Telix swallows it); OSC 10 prints on all of those and on Telix. An empty APC prints on Telix, Terminate and Qmodem.
- **Never send ENQ.** No terminal recorded here answers it, and every CP437 terminal draws it as a glyph, SyncTERM and IcyTerm included.
